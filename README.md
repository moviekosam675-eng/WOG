# WOG App

## Project Structure

The WOG App has a well-defined project structure that helps in managing the codebase effectively. Below is an overview of the directories and files:

- **/src**: This directory contains the source code of the application.
  - **/components**: Reusable UI components.
  - **/screens**: Screens/components that represent different views of the application.
  - **/services**: Services for API calls and data management.

- **/assets**: Contains images, fonts, and other static resources used in the app.

- **/tests**: This directory is for unit and integration tests.

- **package.json**: Contains metadata about the project and dependencies.

## Features

The WOG App has the following features:

- User Authentication: Secure login and registration functionality.
- Profile Management: Users can view and edit their profiles.
- Search Functionality: Easily search through the app's content.
- Notifications: Real-time alerts for users.
- Responsive UI: A seamless experience on both mobile and desktop.

With this structure and features, the WOG App aims to provide a smooth and efficient user experience.
